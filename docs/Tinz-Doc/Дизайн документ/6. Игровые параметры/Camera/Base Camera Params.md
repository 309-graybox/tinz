### 1. **Target**
___
**Type:** `Node`
**Default:** `Null`

**Описание:**
Узел привязки Spring Arm. Назначается отдельно для каждой камеры.

### 2. **Target Offset**
___
**Type:** `Vector3`
**Default:** `(0, 0, 0)`

**Описание:**
Смещение точки привязки в локальных координатах Target. Поворот и масштаб цели влияют на это смещение.

### 3. **Arm Length**
___
**Type:** `Float`
**Default:** `6`

**Описание:**
Желаемая длина Spring Arm в метрах. При коллизии фактическая дистанция сокращается. Значение 0 размещает камеру в точке привязки.

### 4. **Mouse Sensitivity**
___
**Type:** `Float`
**Default:** `0.1`

**Описание:**
Чувствительность мыши: градусов на единицу сырого смещения мыши. Одинакова для Yaw и Pitch. Значение 0 отключает вращение мышью.

### 5. **Min Pitch**
___
**Type:** `Float`
**Default:** `-70`

**Описание:**
Минимальный угол Spring Arm в градусах. При приближении к нему может включаться Min Angle Bias.

### 6. **Max Pitch**
___
**Type:** `Float`
**Default:** `70`

**Описание:**
Максимальный угол Spring Arm в градусах. Должен быть не меньше Min Pitch.

### 7. **Invert Pitch**
___
**Type:** `Bool`
**Default:** `False`

**Описание:**
Инвертирует направление вертикального управления мышью.
