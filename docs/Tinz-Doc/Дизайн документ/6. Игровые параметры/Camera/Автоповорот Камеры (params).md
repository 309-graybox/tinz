### 1. **Enable Auto Rotation**
___
**Type:** `Bool`
**Default:** `True`

**Описание:**
Включает автоматический поворот по Yaw. При выключении остальные параметры механики скрываются, их значения сохраняются.

### 2. **Response Time (s)**
___
**Type:** `Float`
**Default:** `3`

**Описание:**
Время устранения примерно 95% фиксированной ошибки угла из состояния покоя, без ограничения максимальной скорости. Плавный разгон встроен в отклик. Больше — медленнее. При 0 остаётся только ограничение Max Angular Speed.

### 3. **Resume Delay**
___
**Type:** `Float`
**Default:** `1`

**Описание:**
Задержка в секундах после последнего ручного вращения камеры. Отсчитывается и во время движения, и на месте. Начало движения само по себе таймер не запускает. Значение 0 убирает ожидание.

### 4. **Max Angular Speed (deg/s)**
___
**Type:** `Float`
**Default:** `180`

**Описание:**
Максимальная скорость автоповорота в градусах в секунду. Ограничение может увеличить фактическое время реакции. Значение 0 останавливает автоповорот.

### 5. **Min Movement Speed (m/s)**
___
**Type:** `Float`
**Default:** `1.5`

**Описание:**
Минимальная горизонтальная скорость цели для работы механики. При 0 всё равно требуется фактическое движение.
