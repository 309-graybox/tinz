### 1. **Enable Position Lag**
___
**Type:** `Bool`
**Default:** `True`

**Описание:**
Включает сглаживание точки привязки Spring Arm. При выключении точка следует за целью сразу; настройки позиционного лага скрываются, но сохраняются.

### 2. **Horizontal Follow Time (s)**
___
**Type:** `Float`
**Default:** `0.625389993`

**Описание:**
Время в секундах для устранения примерно 95% неподвижной ошибки по горизонтали. Меньше — отзывчивее, больше — сильнее отставание. Значение 0 убирает горизонтальное сглаживание.

### 3. **Vertical Follow Time (s)**
___
**Type:** `Float`
**Default:** `0.625389993`

**Описание:**
Такое же время для вертикали, по мировой оси Z. Значение 0 позволяет сразу следовать за высотой цели.

### 4. **Max Pivot Lag (m)**
___
**Type:** `Float`
**Default:** `3`

**Описание:**
Максимальное общее расстояние между целью и сглаженной точкой, в метрах. Ограничение сферическое и может переопределять плавность следования. Значение 0 убирает позиционное отставание.

### 5. **Enable Rotation Lag**
___
**Type:** `Bool`
**Default:** `False`

**Описание:**
Включает сглаживание ручного поворота. Автоматические оси используют собственное сглаживание и повторно через Rotation Lag не проходят. При выключении поле времени скрывается.

### 6. **Rotation Response Time (s)**
___
**Type:** `Float`
**Default:** `0.2965`

**Описание:**
Время устранения примерно 95% фиксированной угловой ошибки из состояния покоя. Камера плавно разгоняется и замедляется. Больше — мягче, 0 — без сглаживания.
