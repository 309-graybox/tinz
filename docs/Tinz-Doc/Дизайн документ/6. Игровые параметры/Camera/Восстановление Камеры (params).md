### 1. **Enable Camera Recovery**
___
**Type:** `Bool`
**Default:** `True`

**Описание:**
Включает восстановление Pitch при движении. При выключении остальные настройки механики скрываются, значения сохраняются.

### 2. **Response Time (s)**
___
**Type:** `Float`
**Default:** `5.164`

**Описание:**
Время устранения примерно 95% фиксированной ошибки Pitch из состояния покоя, без ограничения скорости. Плавный разгон встроен. Больше — мягче и медленнее. При 0 остаётся ограничение Max Angular Speed.

### 3. **Activation Delay**
___
**Type:** `Float`
**Default:** `1`

**Описание:**
Задержка в секундах движения после ручного изменения Pitch. На месте отсчёт приостанавливается. Значение 0 убирает ожидание.

### 4. **Target Pitch Min**
___
**Type:** `Float`
**Default:** `0`

**Описание:**
Нижняя граница комфортного диапазона Pitch, в градусах. Настраивается внутри ограничений Min Pitch / Max Pitch.

### 5. **Target Pitch Max**
___
**Type:** `Float`
**Default:** `15`

**Описание:**
Верхняя граница комфортного диапазона Pitch, в градусах. Внутри диапазона восстановление не вмешивается; снаружи стремится к ближайшей границе.

### 6. **Max Angular Speed (deg/s)**
___
**Type:** `Float`
**Default:** `180`

**Описание:**
Максимальная скорость восстановления Pitch, в градусах в секунду. Значение 0 останавливает коррекцию.

### 7. **Min Movement Speed (m/s)**
___
**Type:** `Float`
**Default:** `1.5`

**Описание:**
Минимальная горизонтальная скорость цели для восстановления и отсчёта задержки. При 0 всё равно требуется движение.
