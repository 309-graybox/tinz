### 1. **Enable Smooth Return**
___
**Type:** `Bool`
**Default:** `True`

**Описание:**
Включает плавное удлинение Spring Arm после сокращения коллизией. Без него камера сразу занимает текущую разрешённую позицию. Доступен при включённой коллизии.

### 2. **Return Time (s)**
___
**Type:** `Float`
**Default:** `0.6`

**Описание:**
Время восстановления примерно 95% фиксированной доступной дистанции из состояния покоя, после задержки. Плавный старт и замедление встроены. Значение 0 возвращает сразу после задержки. Сокращение из-за коллизии всегда мгновенное.

### 3. **Return Delay**
___
**Type:** `Float`
**Default:** `0.1`

**Описание:**
Задержка в секундах после фактического сокращения плеча. Новое сокращение запускает её заново. Возврат возможен и при частичном освобождении пути. Значение 0 убирает ожидание.
