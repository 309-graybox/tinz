### 1. **Enable Camera Collision**
___
**Type:** `Bool`
**Default:** `True`

**Описание:**
Включает проверку препятствий вдоль Spring Arm. При выключении скрываются параметры коллизии и Smooth Return.

### 2. **Collision Sphere Radius**
___
**Type:** `Float`
**Default:** `0.1`

**Описание:**
Радиус проверочной сферы в метрах. Определяет зазор камеры от геометрии. При 0 используется луч, который не учитывает объём камеры.

### 3. **Camera Collision Mask**
___
**Type:** `Mask`
**Default:** `1`

**Описание:**
Маска объектов, участвующих в проверке. Для сферы используется коллизия, для луча — intersection mask. При 0 препятствия не учитываются. Иерархия отслеживаемого объекта исключается из проверки.
